# Como usar no diagrams.net/draw.io

O arquivo **`fluxograma_bbb_drawio.xml`** já é compatível com o diagrams.net/draw.io (ele é um XML do formato deles), mas você precisa **importar**, não “abrir como texto”.

## Passo a passo (garantido)

1. Abra: https://app.diagrams.net/
2. Vá em **File → Import From → Device**
3. Selecione:
   - `c:/xampp/htdocs/bbb-simulator/fluxograma_bbb_drawio.xml`
4. O diagrama deve aparecer.
5. Para exportar em PDF:
   - **File → Export as → PDF**

## Se der erro de import

Me diga exatamente qual erro aparece (copie/cole a mensagem). Aí eu ajusto o XML para a versão exata do seu diagrams.net.
